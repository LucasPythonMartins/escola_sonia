Instalação do VirtualBox

Para instalar o VirtualBox, siga os passos abaixo:

  1. Acesse o site oficial do VirtualBox: https://www.virtualbox.org/
  2. Selecione a versão adequada para o seu sistema operacional.
  3. Execute o instalador.
  4. Siga as instruções do assistente de instalação.Como pode ver nas imagens abaixo, a instalação é muito simples.Basta clicar em "next" até concluir.

    5. Atenção: Durante a instalação você ficará sem acesso à internet.

  5. Após a instalação, se tudo estiver correto, o VirtualBox abrirá automaticamente como na imagem abaixo.
